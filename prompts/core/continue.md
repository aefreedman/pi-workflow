You were interrupted. Before resuming, recover the authority record: authorized phase and the user instruction establishing it, exact scope/targets and non-goals, permitted artifact writes, prohibited actions, and unresolved decisions. Preserve that record in clarification answers, delegated task packets, and the next handoff; missing or conflicting authority requires one targeted clarification before mutation. Do not write or update an authority file just to record resumption.

“Continue,” a design-detail approval, or a child recommendation does not authorize an implementation transition. Resume only within the existing phase; require an explicit user instruction to implement the resolved scope before changing it, and preserve remaining restrictions. Investigation-only/planning still prohibits source/asset writes, project saves, checkins, and mutating evals. An interrupted or timed-out operation has uncertain effects; do not infer that it never happened or redispatch it blindly.
